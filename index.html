Scoped sensitivity converter

eDPI:   cm/360:

Formula: cm/360 = 360 / (sens × 0.0066 × DPI) × 2.54. Zoomed sens is a % in Options → Controls → hero → “Relative aim sensitivity while zoomed”. 0% MDM = 100·tan(zoomVFOV/2)/tan(baseVFOV/2) ≈ 37.89 at FOV 103 (zoom vFOV 30°). Note: the game default is 30, which is slower than 0% MDM — not equal to it. 360° matching = 100. Hipfire sens doesn't change the zoom % (it's relative), but eDPI/cm values do.
